# Projeto DevMedia

Este projeto é uma aplicação web desenvolvida para oferecer uma experiência funcional e intuitiva aos usuários. Ele reúne recursos de navegação, apresentação de conteúdo e interação com o sistema, com foco em praticidade, organização e fácil uso no navegador.

## O que o projeto faz

- Calcula salarios x inflação de 2010 a 2020 baseando-se nas mudanças ao longo dos anos;
- Calcula IPCA de 2010 a 2020 baseando-se nos valores corrigidos ao longo desse período;
- Calcula e mostra a diferença entre salário x inflação x IPCA de cada ano.

## Tecnologias utilizadas

- Javascript
- Nodejs
